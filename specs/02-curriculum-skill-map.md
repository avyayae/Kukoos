# Curriculum Skill Map — US Common Core, Grades 2–3

Each **skill** is the smallest teachable unit and maps to a CCSS code. Skills are grouped into **units** (map nodes) and **worlds** (map regions).
`prereqs` define the unlock graph. Difficulty levels (1–5) are generator parameters (number ranges, where regrouping happens, missing-number variants, etc.).

**Story arc:** Kukoos flies from Earth's animal habitats into space. Each cleared world rescues an animal friend 🐾 or discovers a planet 🪐 for the sticker album.
**First player's focus:** regrouping (carry/borrow) at 2-digit, then 3-digit. Within-100 basics without regrouping are already known, so they're *pre-mastered* and serve as warm-up review.

## Teaching progression for regrouping skills (concrete → pictorial → abstract)
Each 🎯 skill moves through three phases as mastery grows:
1. **Blocks** (`tradeBlocks`, mastery < 0.3): physically trade a ten rod for 10 ones with animation.
2. **Guided column** (`column` guided, 0.3–0.6): Kukoos highlights each column and asks "Do we need to trade?"
3. **Free column / numeric** (> 0.6): solve independently. The blocks visual is available as a hint.

## Misconception catalog
Implemented in `src/domain/arithmetic/misconceptions.ts`. Each bug is *simulated*, and a wrong answer that equals a simulated answer is that misconception. The authoritative table, with priority rules and known collisions, is in `specs/features/003-domain-core/spec.md`.

| Key | Applies to | Simulated answer | Example (correct) |
|---|---|---|---|
| `sub.smallerFromLarger` | subtraction | digit-wise \|aᵢ − bᵢ\|, no borrowing | 36 − 28 → 12 (8) |
| `sub.borrowNoDecrement` | subtraction | borrows 10 but never reduces the next column | 52 − 28 → 34 (24) |
| `sub.acrossZeroSkip` | borrowing across a 0 | the lending 0 becomes 10 instead of 9 | 403 − 178 → 235 (225) |
| `add.forgotCarry` | addition | digit-wise sum mod 10, carries dropped | 47 + 38 → 75 (85) |
| `add.wroteWholeSum` | addition | writes each column's full sum side by side | 47 + 38 → 715 (85) |
| `wrongOperation` | add & sub | added instead of subtracted, or vice versa | 36 − 28 → 64 (8) |
| `offByOne` / `offByTen` | all numeric | \|answer − correct\| = 1, or ∈ {10, 100} | — |

## Mastery rules (applies to all skills)
- `mastery ∈ [0,1]`, updated after each attempt: `m ← m + α·(score − m)` with α = 0.15; score = 1 (first try), 0.5 (correct after hint), 0 (wrong). Weighted up for higher difficulty.
- **Crowned (mastered):** m ≥ 0.85 and ≥ 15 attempts across ≥ 2 sessions.
- **Pre-mastered** (skills before the parent-chosen start): m = 0.9, crowned, SRS box 3, so they appear as occasional quick reviews. If she gets them wrong, mastery drops normally and the node un-crowns.
- **Spaced review (Leitner):** boxes 1–5 with intervals 1, 2, 4, 7, 14 days. Correct → box+1, wrong → box 1.
- **Difficulty staircase in a lesson:** 2 correct in a row → +1 level; 1 wrong → −1 level (bounded 1–5).
